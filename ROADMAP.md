# Roadmap

## v0.1 — trustworthy local comparison

- Isolated detached git worktrees
- Variant overlays and removals
- Repeated trials with deterministic checks
- Timeout and allowed-path gates
- Diff, duration, transcript, and explicit token-usage evidence
- JSON, Markdown, and self-contained HTML reports

## Next

- First-class Codex, Claude Code, and OpenCode transcript adapters
- pass@k confidence intervals and paired-run statistics
- Skill invocation and instruction-adherence evidence
- Cost fields with explicit provider pricing snapshots
- Import tasks from repository issue/commit history
- Optional sandbox adapters for Docker and platform-native isolation
- GitHub Action regression gate with explicit spending controls

## Non-goals

- A public model leaderboard
- An LLM-as-judge score presented as ground truth
- Installing or authenticating agent providers
- Running untrusted commands without an explicit sandbox
- Claims that one or two trials establish a statistically reliable winner
